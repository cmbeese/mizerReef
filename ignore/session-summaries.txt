CHANGES SUMMARY
---------------

1. REMOVED HARDCODED LOGIC
   
   Previous implementation in reefDegrade():
   - Used hardcoded severity vectors:
     * sev_bleach  = c(0.1, 0.1, rep(0.9, 8))  # for "rubble" trajectory
     * mild_bleach = c(0.3, 0.7, rep(0.9, 8))  # for "algae" and "recovery"
   - Had conditional logic checking trajectory names:
     * if (trajectory == "algae") { ... }
     * if (trajectory == "rubble") { ... }
   - Hardcoded algae boost values:
     * Bleaching year: growth 1.11×, capacity 2× (but applied growth TWICE by mistake!)
     * Post-bleaching years 1-3: only growth 1.11×
   - Assumed exactly 10 refuge bins (rep(0.9, 8) hardcoded)
   
   All of this has been removed and replaced with parameterizable vectors.

2. NEW PARAMETERIZATION SYSTEM
   
   Added three new parameters to setDegradation():
   
   a) algae_boost (logical, default = FALSE)
      - Master switch to enable/disable algae dynamics adjustments
      - When FALSE, only refuge degradation occurs (via deg_scale)
      - When TRUE, applies growth and capacity multipliers
   
   b) algae_growth_boost (numeric vector, default = c(1.11, 1.11, 1.11, 1.11))
      - Multipliers for algae growth rate at each time point
      - Applied by multiplying CURRENT growth rate (compounding)
      - Element 1 = bleaching year (time = t_bleach)
      - Element 2 = first year post-bleaching (time = t_bleach + 1)
      - Element 3 = second year post-bleaching (time = t_bleach + 2)
      - And so on...
      - Vector length determines how many years to apply boosts
      - Must contain only positive values (validated)
   
   c) algae_capacity_boost (numeric vector, default = c(2.0))
      - Multipliers for algae carrying capacity at each time point
      - Applied by multiplying CURRENT capacity (compounding)
      - Same indexing structure as growth_boost
      - If shorter than growth_boost, automatically padded with 1s (no change)
      - Must contain only positive values (validated)
   
   How indexing works:
   - Index 1 corresponds to bleaching year (year 0)
   - Index 2 corresponds to post-bleaching year 1
   - Index 3 corresponds to post-bleaching year 2
   - boost_idx = years_post + 1
   
   Storage in params object:
   - params@other_params$algae_boost (logical)
   - params@other_params$algae_growth_boost (vector)
   - params@other_params$algae_capacity_boost (vector)

3. DEFAULT VALUES
   algae_growth_boost = c(1.11, 1.11, 1.11, 1.11)   # 4 years of 11% boost
   algae_capacity_boost = c(2.0)                    # 2x boost at bleaching only
   
   Auto-padding: If capacity_boost is shorter than growth_boost, it's 
   automatically padded with 1s (no change) for remaining years.

4. COMPOUNDING BEHAVIOR
   Each year multiplies the CURRENT value by the boost factor:
   - Year 0: initial_value × 1.11
   - Year 1: (initial_value × 1.11) × 1.11 = initial_value × 1.11²
   - Year 2: (initial_value × 1.11²) × 1.11 = initial_value × 1.11³
   - Year 3: (initial_value × 1.11³) × 1.11 = initial_value × 1.11⁴

5. BUG FIXES
   
    Original bug in bleaching year code:
    ```
    a_growth <- params@other_params$algae$growth
    new_a_growth <- 1.11*a_growth
    params@other_params$algae$growth <- 1.11*new_a_growth  # WRONG!
    ```
    This applied the boost TWICE: 1.11 × 1.11 = 1.2321
   
    Fixed implementation:
    ```
    a_growth <- params@other_params$algae$growth
    params@other_params$algae$growth <- growth_boosts[1] * a_growth  # CORRECT
    ```
    Now applies the boost exactly once at bleaching year.
   
    Validation added in setDegradation():
    - Checks that algae_growth_boost is numeric and all values > 0
    - Checks that algae_capacity_boost is numeric and all values > 0
    - Checks that deg_scale is a matrix/data.frame with at least 1 column
    - Auto-pads capacity_boost if shorter than growth_boost:
       * algae_capacity_boost <- c(algae_capacity_boost, 
                                                   rep(1, length(algae_growth_boost) - length(algae_capacity_boost)))

6. IMPLEMENTATION DETAILS
   
    reefDegrade() function logic flow:
   
    Base case (before bleaching):
    - if (time < t_bleach) return(rd)
    - Returns original refuge density, no modifications
   
    Recursive call:
    - old_rd <- reefDegrade(params, n, n_pp, n_other, t = t-1)
    - Gets previous timestep's refuge density
    - Prevents infinite recursion via base case
   
    At bleaching year (time == t_bleach):
    - Applies deg_scale[, 1] to refuge density
    - If algae_boost == TRUE:
       * Gets current algae growth from params@other_params$algae$growth
       * Multiplies by growth_boosts[1]
       * Stores result back in params@other_params$algae$growth
       * Same process for capacity using capacity_boosts[1]
    - Updates params@time_modified
    - Returns new_rd
   
    Post-bleaching years (time > t_bleach):
    - Calculates years_post = time - t_bleach
    - Checks if (years_post + 1) <= ncol(deg_scale)
    - If yes:
       * Applies deg_scale[, years_post + 1] to refuge density
       * If algae_boost == TRUE:
          - Calculates boost_idx = years_post + 1
          - If boost_idx <= length(growth_boosts):
             * Gets current growth, multiplies by growth_boosts[boost_idx]
          - If boost_idx <= length(capacity_boosts):
             * Gets current capacity, multiplies by capacity_boosts[boost_idx]
       * Returns new_rd
    - If no, returns old_rd (no more degradation)
   
    Key implementation details:
    - NO separate algae_boost_years parameter - vector length is duration
    - Direct indexing: boost_idx = years_post + 1
    - Always multiplies CURRENT value (enabling compounding)
    - Checks vector length before applying to avoid out-of-bounds errors
    - Auto-padding of capacity_boost happens in setDegradation(), not reefDegrade()

BENEFITS OF NEW DESIGN
-----------------------
✓ Fully flexible: Users can specify any boost pattern without code changes
✓ Simpler: Vector length determines duration automatically
✓ Cleaner: No hardcoded trajectory logic in reefDegrade()
✓ More intuitive: Direct vector indexing by year
✓ Type-safe: Validation checks ensure positive numeric values
✓ Maintainable: All bleaching parameters in one place (setDegradation)

EXAMPLE USAGE
-------------
# Basic usage with defaults (matches original "algae" trajectory):
params <- setDegradation(params, 
                         deg_scale = algae_scale,
                         bleach_time = 2,
                         algae_boost = TRUE)

# Custom boost pattern (e.g., strong initial impact, gradual recovery):
params <- setDegradation(params,
                         deg_scale = custom_scale,
                         bleach_time = 5,
                         algae_boost = TRUE,
                         algae_growth_boost = c(1.5, 1.3, 1.2, 1.1, 1.05),
                         algae_capacity_boost = c(3.0, 2.0, 1.5))

# No algae boost (only refuge degradation):
params <- setDegradation(params,
                         deg_scale = rubble_scale,
                         bleach_time = 2,
                         algae_boost = FALSE)
