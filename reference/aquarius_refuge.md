# Competitive method refuge parameters for a generic Caribbean reef

This is a 2-dimensional array containing start and end lengths for size
bins and `prop_protect` for each size bin, which gives the refuge
density per square meter for ten 5cm wide fish length bins ranging from
0 to 50 cm. Data from the Aquarius reef study site.

## Usage

``` r
aquarius_refuge
```

## Format

A MizerParams object
