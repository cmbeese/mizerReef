# Interaction matrix for a generic Caribbean reef (10 functional groups)

The predator-prey interaction matrix for the 10-group Caribbean reef
model. Rows represent predators, columns prey. Values encode the
relative vulnerability of each prey group to each predator.

## Usage

``` r
caribbean_10_interaction
```

## Format

A numeric matrix (10 x 10).
